# Business Research System

Business-domain intelligence for the gludd agent platform. The `entity_research`
role discovers organizations, maps corporate associations, inventories assets,
assesses public exposure and risks, and profiles consumer demographics — all
through structured research with explicit opt-in toggles.

## Architecture Overview

### Data flow

1. **Agent** invokes the role with entity identity (name, domain, jurisdiction)
   and category enable flags
2. **Role** queries data sources through their APIs with rate limiting
3. **entity_graph** module builds association networks and generates DOT-format
   graph visualizations
4. **SearX** continuous monitoring runs on a configurable interval, alerting on
   newsworthy events (acquisitions, breaches, funding, lawsuits)
5. **Output** written to `entity_research_output_dir` in JSON, Markdown, DOT,
   and CSV formats

## Research Capabilities

### Discovery

Basic entity identification: legal name, jurisdiction of incorporation,
registration number, company status (active, dissolved, in liquidation),
incorporation date, and registered address. Queries OpenCorporates for
official registry data and Wikipedia for public articles.

### Associations

Corporate relationship mapping: parent companies, subsidiaries, directors
and officers, major shareholders, joint ventures, and known business
partners. The association graph is built to `association_max_depth` levels
with a cap of `association_max_nodes` to prevent runaway traversal.
DOT-format output enables graph visualization.

### Assets

Entity-owned asset inventory: IP address blocks (ARIN/RIPE/APNIC WHOIS),
domain names (WHOIS + DNS), registered trademarks (USPTO), patents (USPTO,
WIPO), and SSL/TLS certificates (crt.sh, certificate transparency logs).

### Exposure

Public-facing surface analysis: open ports and services (Shodan, Censys),
technology stack fingerprinting, known CVEs affecting detected software,
and SSL/TLS configuration assessment. Requires `entity_domain` or known
IP blocks.

### Risks

Multi-factor risk scoring: legal risks (active litigation, regulatory
actions, sanctions lists), financial risks (bankruptcy filings, debt
ratings, going-concern warnings), and reputational risks (data breaches,
regulatory fines, adverse media). Each finding includes a confidence
score; those below `entity_research_risk_confidence_threshold` are
filtered out.

### Demographics

Consumer profiling: audience segments and personas, market position,
brand sentiment analysis, and competitive landscape mapping. Uses
publicly available market research and news sentiment.

## SearX Continuous Monitoring

When `entity_research_searx_monitor: true`, the role registers a recurring
check via the managed SearX instance:

| Variable | Default | Description |
|---|---|---|
| `entity_research_searx_check_interval_hours` | `24` | Hours between SearX check runs |
| `entity_research_searx_alert_on_risk_threshold` | `0.7` | Risk score threshold for alerting |
| `entity_research_searx_alert_topics` | `[acquisition, breach, funding, layoff, leadership, lawsuit, bankruptcy]` | Topics that trigger alerts |

SearX is used for:
- News monitoring for the tracked topics
- CVE and vulnerability research against detected software assets
- Regulatory and legal news relevant to the entity's jurisdiction
- Data source version and freshness checks

## Security

- All API keys loaded from environment or secrets backend — never hardcoded
- `psk` variable is `no_log: true` on every task accessing the daemon
- Rate limiting enforced via `entity_research_api_delay_seconds` between API calls
- All category toggles default to `false` — no data is collected without explicit opt-in
- Output files written with mode `0644` to `entity_research_output_dir`
- API credentials validated at task start; missing credentials for enabled
  sources produce a clear error rather than a silent skip
