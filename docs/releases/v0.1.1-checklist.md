# v0.1.1 pre-release checklist

Run this checklist from the main checkout in order. Stop and fix every non-zero
exit; do not skip a failed lane or substitute a locally built release artifact.

## 1. Repository and version

```text
make git-status
make check-version-consistency
make check-readme-status TAG=v0.1.1
make check-changelog-accuracy TAG=v0.1.1
make check-runbook-currency TAG=v0.1.1
make release-dry-run TAG=v0.1.1
```

Expected: clean main checkout, version `0.1.1` everywhere, current README
status, accurate CHANGELOG entry, current runbook, and a successful dry run.

## 2. Full quality gate

```text
make gate
make test-count
```

Expected: full gate PASS, zero collection errors, aggregate coverage at least
85%, every measured file at least 75%, and no unremediated warning or error.

## 3. Push development and verify exact-SHA CI

```text
make development-push
make verify-remote BRANCH=development SHA=<development-full-sha>
make ci-verdict-safe BRANCH=development
```

Expected: remote development equals the local SHA and that exact SHA has a
completed successful workflow. Pending, missing, cancelled, or stale is red.

## 4. Promote and cut

```text
make development-merge-to-master
make verify-remote BRANCH=master SHA=<master-full-sha>
make release-cut TAG=v0.1.1 MSG='v0.1.1: S83.166 release documentation and version bump'
```

Expected: the tag points at the CI-green master SHA and starts the complete
release workflow.

## 5. Tag workflow evidence

Confirm every blocking job is green:

- gate on Python 3.11 and 3.12;
- every test shard, merged coverage, and Molecule shard;
- Linux x86_64, Linux aarch64, macOS arm64, and Windows x86_64;
- container health smoke;
- Ansible execution-environment build/import smoke;
- release functional matrix before the publishing action.

## 6. Published artifact verdict

```text
make verify-release-completeness TAG=v0.1.1
make release-view TAG=v0.1.1
```

Expected: all required categories pass, non-empty assets exist,
`isDraft=false`, and the release URL identifies `v0.1.1`.

Required evidence to record:

- exact tag and commit SHA;
- full gate and coverage evidence;
- tag workflow URL;
- release URL;
- `COMPLETENESS CHECK: PASS`;
- container and Ansible EE digest references.

If any item is missing, v0.1.1 is not shipped. Follow
`docs/RELEASE_RUNBOOK.md`; never back-fill with local artifacts.
