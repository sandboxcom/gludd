## Highlights

v0.1.1 is the universal accelerator, model-routing, and release-reliability
milestone. It contains 826 commits after v0.1.0-beta.4 and ships functional code,
tests, infrastructure, collections, and cross-platform artifacts. Self-improvement
is its primary acceptance workload, while discovery, scheduling, placement,
model execution, and evidence remain reusable Gludd capabilities.

- **Universal accelerators:** provider-neutral discovery and right-sizing cover
  local GPU/TPU devices, Slurm, Azure Container Apps, and Azure VM/VMSS plans,
  including multi-device runner topology where the provider supports it.
- **Universal workloads:** polymer-design and Arduino-class firmware tasks use
  the same scheduler, model gateway, policy, placement, provenance, and
  validation contracts as self-improvement.
- **FreeLLMAPI boundary:** upstream source/catalog admission, exact Node 20/22
  builds, isolated scoring evaluation, frozen-corpus evidence, and rollback
  receipts are integrated without embedding FreeLLMAPI's server or scheduler.
- **Release rigor:** 46 published assets include native packages, Python
  distributions, four Ansible collections, container/EE metadata, SBOM,
  checksums, licenses, a release manifest, and platform smoke attestations.

## Known Issues / Not Yet Done

- Azure accepted the bounded Container Apps deployment but placed zero T4
  replicas, so positive GPU-utilization and an accepted mixed-provider live task
  remain open evidence rather than a claimed success.
- The evaluated FreeLLMAPI v0.11.1 candidate remains non-runtime-admitted. Its
  live provider probe received HTTP 429, and cross-engine/promotion gates remain
  fail-closed.
- The published tag is annotated but unsigned. The 46 release assets carry an
  exact source manifest and SHA-256 index, but the tag workflow did not create a
  signed GitHub/Sigstore SLSA attestation. The immutable public tag and assets
  were not rewritten; both exceptions are recorded in
  `docs/releases/audit-0.1.1.json`, and the workflow is fixed forward.
- These limitations do not weaken local/universal execution or the existing
  digest-pinned admitted FreeLLMAPI capability; follow-up evidence remains in
  `TASKS.md`.

## Upgrade Notes

- Review deployment and database migrations before upgrade; v0.1.1 is not a
  documentation-only release.
- Pin container and Ansible EE deployments by the immutable digests recorded in
  the release metadata.
- Follow `docs/RELEASE_RUNBOOK.md` for installation, verification, and rollback.
