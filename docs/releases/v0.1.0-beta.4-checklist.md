# v0.1.0-beta.4 Pre-Release Checklist

Concrete, in-order preflight for cutting `v0.1.0-beta.4`. Run each step on the
**main checkout** (`/Users/shawnwilson/gludd`), in order. Stop and fix on any
non-zero exit or unexpected output — do not skip ahead. Companion to
`docs/RELEASE_RUNBOOK.md` and `docs/releases/v0.1.0-beta.4.md`.

## Step 1 — branch reconciliation complete

```text
make branch-reconciliation-summary RECONCILE_TARGET=development RECONCILE_LIMIT=100 RECONCILE_DETAILS=0 RECONCILE_CURRENT_ONLY=0 RECONCILE_QUIET_PROGRESS=0 RECONCILE_HEAD_SEMANTICS=0
```

Expected: the deduplicated-head classification reports **`unique=0`** — every
inventoried branch tip is reachable from `development`. Any `unique>=1` head is
unreconciled work and blocks the release.

## Step 2 — full gate green

```text
make gate-background
make gate-status-check
```

Expected: `.gate-status` = **PASS**, `make test-count` shows **0 collection
errors** (~105,175 collected). A red gate or a stale `.gate-status` (older than
the last edit) blocks the release.

## Step 3 — development pushed

```text
make development-push
make verify-remote BRANCH=development SHA=<local-HEAD>
```

Expected: **`VERIFIED development@<sha>`**. `REMOTE MISMATCH` means the push did
not land — re-run the push before proceeding.

## Step 4 — CI green on development tip

```text
make ci-verdict BRANCH=development
```

Expected: **`conclusion: success`** and **headSha == development tip**. PENDING,
cancelled, or a stale run is not a verdict — treat as red (see runbook "A
cancelled CI run is NOT a verdict").

## Step 5 — README status current

```text
make check-readme-status TAG=v0.1.0-beta.4
```

Expected: **`OK — README status table is current`**, exit 0. `release-cut`
re-runs this gate and aborts on staleness.

## Step 6 — cut the release

```text
make release-cut TAG=v0.1.0-beta.4 MSG='v0.1.0-beta.4: <one-line summary>'
```

Expected: `require-ci-green` and `check-readme-status` pass, push + annotated
tag succeed (triggers the CI release job), `release-view` shows the GitHub
Release. This is the **only** sanctioned release path.

## Step 7 — verify artifact completeness

```text
make verify-release-completeness TAG=v0.1.0-beta.4
```

Expected: **`COMPLETENESS CHECK: PASS — all 16 checks passed.`** — all 12
artifact categories (platform binaries, packages, metadata), non-draft,
prerelease flag matching the `-beta` tag, version-stamped names, no zero-size
assets. A poll timeout after a cold build means "still building" — re-run later.
Paste this PASS line plus the release URL as the TASKS.md completion evidence.
