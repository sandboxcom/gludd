# v0.1.0-beta.4 pre-release checklist

Run this checklist from the main checkout in order. Stop and fix every non-zero
exit; do not skip a failed lane or substitute a locally built release artifact.

## 1. Repository and version

```text
make git-status
make check-version-consistency
make check-readme-status TAG=v0.1.0-beta.4
make release-dry-run TAG=v0.1.0-beta.4
```

Expected: clean main checkout, version `0.1.0-beta.4` everywhere, current
README status, and a successful dry run.

## 2. Runtime and collection boundaries

```text
make validate-ansible-runtime-boundary
make check-collection-python-boundary COLLECTION_PYTHON_BOUNDARY_ROOT=collections/ansible_collections COLLECTION_PYTHON_BOUNDARY_INVENTORY=config/ansible/collection-python-boundary-inventory.json COLLECTION_PYTHON_BOUNDARY_STRICT_ZERO=0
make check-collection-interop
```

Expected: core Python has no Ansible controller dependencies, canonical
execution-environment inputs match their lock hashes, managed-host Python is
explicit, and all FQCN role edges and collection dependencies resolve.

## 3. Sandbox and local-model acceptance

```text
make test-vm
make test-e2e
make test-local-model-pipeline
make test-e2e-games-local-model
```

Expected: hermetic sandbox lifecycle coverage passes, host capability skips are
explicit, local model endpoint lifecycle is bounded and namespaced, and no
model download occurs unless the live opt-in is set.

## 4. Full quality gate

```text
make gate-all
make test-count
```

Expected: full gate PASS, zero collection errors, aggregate coverage at least
85%, every measured file at least 75%, and no unremediated warning or error.

## 5. Push development and verify exact-SHA CI

```text
make development-push
make verify-remote BRANCH=development SHA=<development-full-sha>
make ci-verdict-safe BRANCH=development
```

Expected: remote development equals the local SHA and that exact SHA has a
completed successful workflow. Pending, missing, cancelled, or stale is red.

## 6. Promote and cut

```text
make development-merge-to-master
make verify-remote BRANCH=master SHA=<master-full-sha>
make release-cut TAG=v0.1.0-beta.4 MSG='v0.1.0-beta.4: sandbox, local-model, runtime-boundary, and artifact-matrix hardening'
```

Expected: the tag points at the CI-green master SHA and starts the complete
release workflow.

## 7. Tag workflow evidence

Confirm every blocking job is green:

- gate on Python 3.11 and 3.12;
- every test shard, merged coverage, and Molecule shard;
- Linux x86_64, Linux aarch64, macOS arm64, and Windows x86_64;
- container health smoke;
- Ansible execution-environment build/import smoke;
- release functional matrix before the publishing action.

Confirm packaged-smoke attestations exist for tar, deb, rpm, dmg, zip, NSIS,
arm64 tar, wheel, sdist, three locked collections, Ansible EE, container, SBOM,
and install script.

## 8. Published artifact verdict

```text
make verify-release-completeness TAG=v0.1.0-beta.4
make release-view TAG=v0.1.0-beta.4
```

Expected: all 28 categories pass, at least 30 non-empty assets exist,
`isDraft=false`, and `isPrerelease=true`.

Required evidence to record:

- exact tag and commit SHA;
- full gate and coverage evidence;
- tag workflow URL;
- release URL;
- `COMPLETENESS CHECK: PASS`;
- container and Ansible EE digest references;
- ZDD promotion and rollback digest.

If any item is missing, beta4 is not shipped. Follow
`docs/RELEASE_RUNBOOK.md`; never back-fill with local artifacts.
