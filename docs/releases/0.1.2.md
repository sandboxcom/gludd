# v0.1.2 release notes

**Version:** 0.1.2
**Prior release:** v0.1.1
**Status:** Unreleased; CHANGELOG date 2026-10-09.

## Highlights

v0.1.2 is the security-hardening, reliability, and fast-gate-admission milestone.
It contains the six formally completed post-v0.1.1 backlog items plus release-prep
fixes that repaired hosted Molecule scenarios, PyInstaller warning allowlists, and
the local gate admission path.

- **Fail-closed chemistry entities:** typed unknown-structure sentinel is the only
  permitted empty structure state; inconsistent structures fail closed and
  stereo/isotope evidence stays conservative.
- **Standards-consistent X.509 chains:** certificate issuance and chain building
  enforce proof of possession, issuer/key use, path length, validity, and
  caller-supplied trust across RSA, ECDSA, and Ed25519.
- **Monotonic timing state:** debounce, throttle, and watchdog APIs preserve a
  valid zero clock epoch, independent edge/task ownership, finite delays, moving
  quiet periods, and idempotent watchdog registration.
- **Authenticated TLS 1.3:** exact handshake frames, context-bound
  CertificateVerify/Finished authentication, poisoned failure state, and
  independent application record protectors are enforced.
- **Worktree-safe venv reclamation:** cleanup preserves the invoking worktree,
  refuses active peers and stale or unreadable registration evidence, and reclaims
  only inactive registered peers.
- **Fast gate admission:** deterministic full-gate failure families are assigned
  to bounded fast-admission owners while the full gate remains mandatory release
  proof.
