## 2. How Verified

Every fix was committed only after tests passed and adversarial verification was applied.
Adversarial review caught real bugs that would have shipped:

- **budget `try_charge` wrong signature** — test used `MagicMock` which accepted any call;
  real `SpendLimiter` would have always denied charges. Caught before merge.
- **mcp branch on wrong base** (`abc613a`) — fix was rebased onto stale tree; ancestry check
  revealed it. Redone cleanly as `390ba14`.
- **2 vacuous cli tests** — patches targeted `sys.exit` instead of the actual `httpx.request`
  call site, so tests passed whether or not the fix existed. Repointed in `e59b8a8`.
- **spend `record()` unguarded** — without the guard, a failed charge still incremented the
  counter, enabling cap evasion. Fixed in `3d13541`.
- **`_redact_payload` shallow** — only scrubbed top-level keys; nested payloads (e.g.
  `{"metadata": {"token": "..."}}`) passed through unredacted. Fixed in `b4598b3`.
- **manager 4th leak site** — initial patch covered 3 of 4 exception-to-response paths;
  adversarial re-read found the fourth. Fixed in `7963e23`.

## 4. Process Lessons

These friction points burned time this wave; record them to avoid repeating:

**(a) Worktree agents sometimes reset to the wrong base.**
Always verify with a collect-count and a git ancestry check (`git merge-base --is-ancestor`)
before trusting a fix. Do not assume the agent branched from the intended commit.

**(b) Worktree agents stall mid-sequence on long (~13-step) tasks.**
Multi-step git consolidation (cherry-pick chains, rebase, tag, push) must be done on the main
thread or via a deterministic script — not delegated to a single long-running agent that may
stop responding partway through.

**(c) Explore-type agents flop on `git show`-heavy analysis.**
"Inline budget" confusion causes them to hallucinate commit contents. Use a claude-type
(reasoning) agent for ancestry and diff analysis.

**(d) Verify by content, not reachability.**
`git log --all` showing a commit hash does not mean it is on the intended branch. Use
`git show <sha>` to confirm the actual diff, and `git merge-base --is-ancestor` to confirm
lineage.

**(e) MagicMock hides real-API signature bugs.**
Security-critical guards (spend limits, auth checks, redaction) must be tested with real
instances, not mocks. A mock will silently accept a wrong call signature that the real class
would reject.
