## Notes on the two PARTIALs

passing unit tests. The gap is purely *integration*: the in-source TODO at
`spend_limiter.py:17` indicates `would_exceed`/`try_charge` may not yet be called

restores `snapshot()` from `SpendRepository`. Treat the algorithm as done; the
"does the daemon actually enforce + restore" wiring needs a dispatch-path /
lifespan test before this is closed.

tested, but the cost data they consume is never produced by the real benchmark
aggregate query. This is a silent no-op in production (cost-cap reduces to the
best-score path because all `avg_cost==0.0`). Low blast-radius but real.
