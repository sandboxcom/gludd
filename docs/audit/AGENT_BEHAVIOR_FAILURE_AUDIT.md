# Agent Behavior Failure Audit

This audit records repeated user-observed workflow failures from the beta.1 release session. A behavioral guard only counts when it names the exact failure path, the enforcing code, and the test that exercises it. Broad claims such as "class fixed" are not valid evidence.

## Operating Rule

When asked whether a behavior is fixed, answer with the row name and evidence target. If no row exists, say it is not yet codified. If a row status is partial, do not describe the behavior as fixed.
