## Methodology & Caveats

- Coverage was collected by running `make test-unit PYTEST_ADDOPTS='--continue-on-collection-errors --cov=general_ludd --cov-report=json --cov-report=xml'`.

Coverage therefore reflects only the tests that **successfully collected and ran**.
- **Implication:** files whose *only* tests are in error-collecting test files will show lower-than-true coverage. The percentages below are a **lower bound**. Re-running after fixing the collection errors (installing `tenacity`, resolving fixture imports) would lift many files. The ranking is still directionally accurate: a file at 0–30% has a real gap regardless.
- Per-file percentages come from `.gate-logs/coverage-20260706T212148Z.json` (generated by `scripts/audit_coverage.py`). Missing-line ranges for the bottom 20 come from `coverage.xml`.
