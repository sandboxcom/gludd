## Dispositions

- **R (root):** an operative clause is consolidated in the named root section. Repeated formulations share one clause; actors, triggers, limits, exceptions and proof requirements must remain.
- **H (history):** dated incident narrative/status counts or explanatory rationale stays verbatim in the archived source at the given range. It is optional context, not a new command, current runtime claim or permission.
- **E (example):** exact original examples/quoted patterns remain in the archive. Any instruction or exception an example carries must also be in the root. No example may silently become the only location of a binding rule.
- **P (precedence):** original tensions remain explicit in root; this change does not resolve them by deletion.
- **N (new):** user-requested transparent Make ownership and takeover contract. This is an intentional addition, not represented as an original quotation.

There are no new broad mandatory companion reads. Existing mandatory key-target and enforcement-reference triggers remain in root.
