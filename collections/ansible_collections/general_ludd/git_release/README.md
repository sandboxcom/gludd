# general_ludd.git_release

The Git Mastery and Release Captain Expert collection (spec `GRC-001`).
Provides read-only assessment roles (`repo_assess`, `history_investigate`,
`branch_plan`) backed by the Python evidence module
`general_ludd.git_release.evidence`. Every observation is recorded as
machine-verifiable evidence so downstream planners can distinguish
observations, inferences, proposed mutations, completed mutations, and verified
outcomes.
